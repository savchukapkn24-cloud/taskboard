# Що залишилося перед здачею

1. Увійти в GitHub як savchukapkn24-cloud. Створити порожній публічний репозиторій taskboard.
2. Відправити main і навчальні гілки командою git push. Папка .git містить історію: її не можна втрачати. Просте завантаження файлів через сайт не переносить історію Git.
3. Створити справжні Pull Request-и. Поточні навчальні гілки вже злиті локально; для демонстрації PR потрібні нові зміни в окремих гілках. Локальний merge не замінює GitHub PR.
4. Settings → Pages → Deploy from a branch → main → /(root). Перевірити сайт і оновити README.
5. Запустити index.html через Live Server. У DevTools заповнити Network у docs/report.md, відтворити 404 і зберегти скріншот. Відновити правильний шлях.
6. Перевірити обидві сторінки на validator.w3.org. На ширині 390px перевірити відсутність горизонтальної прокрутки.
7. Відтворити три помилки W-12, виправити, додати фактичні спостереження до звіту.
8. Зберегти реальний скріншот застосунку як images/screenshot.png і додати в README: ![TaskBoard](images/screenshot.png).
